# AHC074 実験記録

目標の平均約6,554点には未到達。現在の提出候補はルートの `main.cpp`。

実行時間制限は2秒。現在の `main.cpp` を `pahcer run` で評価した結果（seed 0–99）は平均 **14,967.92点**、全ケース合法・誤り注文0。最小14,424、最大15,467、1注文の最大操作数39。元の平均32,770点から54.32%削減した。

対話待ちを除くCPU時間の最大は **1.39685秒**。WSLの対話I/Oを含むpahcerの最大実時間8.087秒とは区別する。`validation.json` に全ケースのスコア・誤り・CPU時間・提出ソースのSHA-256を保存した。

調整に未使用だったseed 1000–1049を公式ジェネレータで追加生成し、同じmainを公式テスタで検証した。50ケース平均 **14,967.72点**、最小14,343、最大15,478、誤り0、最大CPU **1.33932秒**。結果は `holdout/results.json`、使用seedは `holdout/seeds.txt` に保存。通常100ケースと未使用50ケースの両方で提出ソースのSHA-256は `78e3e766c6b5b3631f4b6fbc2b4c31bc357b561fee2db04c6886e51773d907c5`。

現在の方式は、既存v3/v4の小ブロック分割から独立に開発した、全64窓をまとめて扱うprefix辞書方式。

- 窓の並びを、商品一覧における隣接窓の一致度を使って焼きなます。白黒反転は各隣接辺に最適な向きを選べる。
- 各紙は、この並びの先頭からある長さまでが不透明で、残りが穴。可視紙の長さは上から狭義増加し、表示は可視紙の連続区間を繋いだものになる。
- 各長さに必要な色を残しつつ、長い紙へ枚数を集中させる。公開された256商品の必要区間数を全体で減らすよう、trie上の動的計画法で紙の色を学習する。
- 注文ごとに、現在の重ね順から目的表示へ達する最小操作数を、状態「確定した窓数・選択紙の元位置の最大値」のDPで求める。同じ操作数なら可視紙を多く残す。
- 選ばれた可視紙集合への合法最短操作を、距離の差分評価で構成する。次の注文に備え、長さの逆転が少ない並びを優先する。
- 最大3個の設計候補を内部生成の注文で比較する。実際の注文列は一切先読みしない。学習はCPU時間1.05秒を過ぎたら更新単位の境界で停止し、途中でも全商品の表示可能性を保つ。

提出ファイルは単独でコンパイルでき、外部ファイル・引数・環境変数に依存しない。設計と各回答の後にflushし、実注文を1つずつ読み、負の応答を受けたら終了する。

最短距離式の検証では、同じ長さの紙が存在する8枚・40,320状態について、選択集合54種類に対する約214万操作を厳密BFSと比較し、不一致0だった。学習期限を0 / 0.06 / 0.18 / 0.45秒に短縮する12ケースも、公式テスタで全件正常。

## 旧4窓ブロック方式の記録

以下は平均26,235.22点だった段階の記録。`validation_26235.json` に当時の100ケース結果を保存している。

前版は平均26,492.83点、元の基準実装は平均32,770.00点。前版のケース別結果は `validation_26492.json`、ソースは `main_26492.cpp` に保存。

旧方式:

- 64窓を4窓ずつに分け、各ブロックを6枚の紙で制御する。残る96枚は全て穴。
- 6枚の720通りの重ね順について、見えている紙だけを動かす有向グラフを構築する。
- 商品分布を使った相対価値反復と逆向きDijkstraで操作を決める。
- 固定方策の到達状態を集め、商品分布に対する定常分布から平均操作数を評価する。
- その平均操作数を基準に、窓の組合せ・順番・白黒反転を同時に焼きなまし法で探索する。実際の注文は先読みしない。
- 最大10万回、または探索のCPU時間0.95秒で打ち切る。最良の組合せを保存し、最後に各ブロックの方策を再計算する。
- 全ブロックを連続した位置に保つため、挿入位置は `6 * group + local_position`。

`baseline.cpp` は元の実装。`block_main.cpp` は平均26,492.83点だった前版のコピー。`pair_main.cpp` は2窓6枚の前段階の候補（seed 0: 32,056）。`build_direct.py` で最新方式の提出用ソースを生成できる。

試した別方式:

- ランダムな多窓模様と不一致数による貪欲法: 局所解と紙の取り出し費用が大きく、改善せず。
- 3商品の共通部分を紙にし、担当商品の交換で共通範囲を拡大: seed 0で表現枚数は平均5.61だが、256商品のうち30商品が表現不能。取り出す操作も別途必要なので、この枚数を操作数として扱ってはいけない。
- 4商品共有: 表現不能2商品、表現枚数平均8.20。
- 8商品共有: 表現不能0商品、表現枚数平均17.29。実操作探索は不十分。
- ビーム探索: 表示が変わらない操作も必要。単なる不一致数では探索が止まる。最初の正しい色までにある誤色の枚数を評価に足しても、現在のブロック方式に及ばない。
- 小ブロックの紙模様の焼きなまし: 4窓6枚で一様分布時の平均約1.67597操作を発見し、現在の候補に採用。
- 複数ブロックの紙を結合した追加紙: 下に残る同じ模様の紙が操作を妨げ、貪欲探索では悪化。`compound.cpp` に保存。
- `check_cutoff.py` で探索を即座に打ち切るケースも公式テスタで検証し、誤り0・有効な操作列を確認した。
