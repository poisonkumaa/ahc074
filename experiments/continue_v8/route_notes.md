`route_pairpartial.cpp` (`0dbf68dd5341647a7303848312c66cbece6154ce2cc0665ae21b1faec691c5f3`): `PAIR68_PARTIAL=0` control, `1` enables. Original pair68 restores every donor-covered ordinary home to its starting order and removes that home's paid moves. If this blocks access to a donor/core, retaining one such home's original moves may make the other removals feasible. For pairs covering at least two actually moved homes, test the complete reset and variants excluding one home, prioritizing lower retained costs. Rebuild the ordinary moved set and tail for each variant, then use the same exact schedule and final-state checks. Log `PAIR68_PARTIAL tried/reached/wins` measures additional outcomes.

Audit: the original static core-color and distance tables are valid for the one immutable actual design; they must be invalidated if later called across different designs in one process. Donor options may include currently invisible cards, but reachability is checked by `orderable`. Reset masks exclude current/old loan homes, target-main home, and both donor homes, avoiding duplicate/lost cards when restoring ordinary shelves. Distinct donor-home restrictions and `rebuild_state` preserve future-router invariants. Parent owns compilation and benchmarking; these files make no favorable-score claim yet.
