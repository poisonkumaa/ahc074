Round 6 global_design experiments (no main/a.out/pahcer files modified)

All scores are 3 official seeds 0..2, E=0, unless stated otherwise.
Diagnostic builds define AHC_LEARNING_BUDGET=100 and AHC_REFINEMENT_BUDGET=100.
Fixed original cut53 + exact R8 baseline: 13276.67.

Prefix design alternatives:
1. round6_frontier.cpp/h, built with round6_frontier_build.py:
   Empty dictionary, descend lengths and cluster products currently requiring
   that prefix length. Suffix-trie q-medoids advance product frontiers; reserve
   enough budget to finish all frontiers with all-1/owner-0 fallback papers.
   CLI maxq, intrinsic refit passes, exact repetitions.
   q6 / q8 / q12, 4 intrinsic passes, no exact: 14883.67 / 15276 / 16426.
   All feasible; only a few high levels disappear, low fallback remains.
2. round6_merge.cpp/h:
   Merge adjacent 2..4 low levels into their highest length, using one fewer
   paper; jointly relearn all destination papers and validate every product.
   All 3 seeds accept 0 modifications. Low single papers are not simply spare.
3. round6_greedy.cpp/h:
   Prior globally greedy allocation (65 universal initial papers +127 extras)
   combined with current exact move-cost learning down to length1 (R8).
   Max extra4/6/8 and minimum extra length32: 14465.33 /13914.33 /13752.33.
4. round6_unique.cpp:
   Prohibit reusing a public product as representative at different long
   lengths in initialization / intrinsic refit / exact refit.
   All modes match baseline scores exactly; baseline already has 150 distinct
   representatives among its 150 length>=43 papers on seed0.
   The builder's excluded-leaf sample initialization has been corrected and
   full-mode 3-seed rerun remains identical.

Top-tail-category model:
  For b tail bits let core=64-b. Pure papers len<=core are unchanged. Every
  higher paper len=core+cat+1 becomes opaque on [0,core) and its one tail bit.
  All other tail positions become holes. Original colors/prototypes retained.

Virtual orientation planner (round6_tailplan.cpp/h):
  Enumerate b! category orders. Map a category at rank r to virtual length
  core+r+1. The first category paper can cover a matching core suffix plus
  its matching own tail. Later category papers are permitted only on the
  edge core+r -> core+r+1, and only when their own tail color matches.
  Thus every category has exactly one selected owner, and all tails are
  correct. Every virtual-visible paper is actually visible, so existing
  prefix legal-move paths are valid. Missing final DP states are explicitly
  handled instead of reading active[n][0].
  b2: 13830.33; b3:14586.33.

Actual-visible paths (round6_tailplan_actual.cpp/h):
  Parent's round6_general_future.h allows all actual-visible papers and moves
  maximizing reduction of virtual fixed_distance, including >1 reductions.
  Future goal-union quality is used for terminal arrangement. Teachers use
  the same planner, not the old direct_final endpoint.
  b1:13276.67 (casewise identical baseline), b2:13781, b3:14493.67.

Actual path selection (round6_tailplan_all.cpp/h):
  Build each orientation's actual move sequence and choose the shortest.
  b2:13732.33 (max CPU2.305s); b3:14413.67 (max CPU5.282s).

Category-access surrogate DP (round6_tailplan_access.cpp/h):
  Standard prefix DP for pure core papers, then a terminal first-category C:
  if q>=h, moved=count(C in [h,q)), optional=(all len>j in [h,q) > moved).
  For another category, tail correction costs 0 if a matching-color owner
  exists before h (already moved by the pure-prefix path); otherwise count
  same-category papers between h and the earliest matching owner. Choose
  one goal per orientation, then evaluate actual paths as above.
  b2:13796.33; b3:14353.33. This is a selection surrogate, not proven to be
  an exact actual-move distance; executed paths are independently verified.

All tail prototypes explicitly check every selected move against the real
opaque mask, reconstruct the actual stack, and verify every final display.
Initial feasibility is checked for all 256 public products. Experimental
failure throws rather than silently emitting an infeasible design.

CLI for all tail prototypes: b, exact R(default8), orientation count limit
(0 enumerates all). Builders read main but do not modify it. They include
their own headers and parent's round6_general_future.h, so are experiment
sources rather than standalone submission artifacts.

Results indicate that adding owners for only the top few bits costs more
than the recovered accessibility. Larger_templates implemented the full
pair-block variant independently; its reported dedicated training result
was ~17322 on seed0 and is not included in this agent's measurements.

All this agent's experimental processes have finished.
