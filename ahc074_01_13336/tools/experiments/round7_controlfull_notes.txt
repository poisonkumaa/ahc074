Round 7: intrinsic fixed-goal control variate (not adopted)
========================================================

Only round7_controlfull* experiment files were created. main.cpp is unchanged.
The design, exact R8 refit, goal-selection DP, and teacher are the baseline.
Only terminal insertion tie-breaking is changed. If direct_moves cannot
realize the proposed terminal permutation in the exact minimum number of
moves, the existing legal shortest-path fallback is used.

Reference goal construction:
For each of the 256 public products, a one-dimensional DP finds a minimum
number of matching prefix segments. The selected paper IDs form a fixed
goal. Its membership is stored as four 64-bit product masks per paper.
Another 64-bit mask per paper tracks those fixed goals for the same product
IDs as the existing dynamic FIFO goal history. The initial sample uses the
same shuffle as selection_teacher; real requests replace the same FIFO bit
in both histories only after answering that request.

For any suffix set of papers relevant to a mandatory-removal condition,
the measured access score is
  4 * popcount(dynamic FIFO union)
  + beta * (popcount(fixed full-256 union)
            - 4 * popcount(fixed FIFO union)).
All six masks use the original exact OR / additional-bit insertion formula.
No product frequencies, DP distance encoding, or future input are changed.
This is a variance-reduction heuristic, not a claim of strict unbiasedness:
the FIFO goals and current paper order are statistically dependent, and
the next product excludes the current one whereas the exact control uses
the unconditional 256-product mean.

Validation:
  beta=0, R8: seeds 0, 1, 2 match baseline stdout byte-for-byte.
  Output bytes: 103815, 104004, 102094.
  Scores: 13343, 13444, 13043.
  CONTROLFULL_CHECK recomputes the full insertion quality from scratch at
  every insertion position and checks the incremental difference. Seed 0,
  beta=1 passed all assertions, and stdout equals the non-check binary.
  All official tester evaluations had E=0 and respected 384 moves/query.

No configuration improved by the requested >=20 points on 10 seeds, so no
30/100-seed or production-deadline run was performed. The fixed intrinsic
goal has about 9.6 records, whereas dynamic minimum-move goals often include
many additional zero-cost records (previous measurements average ~16.6).
That difference may limit correlation of the control with actual access
cost; it is a hypothesis, not a measured causal explanation.

    -o tools/experiments/round7_controlfull
