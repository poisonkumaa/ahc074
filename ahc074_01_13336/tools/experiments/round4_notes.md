# 実操作数による紙模様の再学習

開始時の提出版は `main_13853_final.cpp`、seed 0–99平均13,853.88。
参考としてユーザー提供の `ahc074_v7_main.cpp` を読み、元ファイルは変更していない。
最終版の測定値とhashは `README.md` を参照。

## 採用した変更

初期の紙設計を、公開256商品だけから生成した紙順と次商品の組に対して再学習する。各商品につき8状態、計2048状態を使う。紙の長さは変えず、長さ64から43まで降順に模様を更新する。

状態DPは `(j,h)`。jは表示済み窓数、hは選択済み紙の元の位置の最大値+1。紙zの長さl、元の位置qに対する移動費用は既存のPrefixDPと同じ。色を変えても費用は変わらず、その紙を利用できる開始位置だけが変わる。

長さlの紙を1枚選ぶ経路について、前側の距離Fと後側の距離Bから、各開始位置sに対する最小費用を計算する。長さlを使わず飛び越す経路と、他の同じ長さの紙を使う経路も保持する。これにより候補模様の費用を正確に求められる。商品の末尾側から作るtrie上で費用改善を集計し、最良の模様を1枚ずつ選ぶ。全商品の到達性を保ち、サンプル上の費用が厳密に減る更新だけを採用する。

長さを降順に処理するため、現在の長さ未満のFは、そのpassの初めに求めた値を再利用できる。Bは既に更新済みの長い紙から1段ずつ確定できる。この再利用は費用の近似ではない。

初期trie学習では、部分木の葉数より多くの模様を選ぶ不可能な状態を省略した。操作生成では最終紙順を先に計算し、動かす必要がある可視紙を1枚ずつ最終順序に挿入する。直接の経路生成が成立しなければ従来の距離減少操作へ戻す。

## 採用しなかった変更

- v7原版は10seed平均13,817.0。4候補を完走する高速化版は100seed平均13,783.11だったが、実操作費用の再学習を優先した。
- 商品別256bit履歴は、各商品4状態・1回学習では小改善したが、2回学習後には64状態履歴より悪化。最終版は64状態を維持した。
- 初期の全0模様、初期refit1/2回は、R8再学習後も既定の全1模様・refit4回を超えなかった。
- 長さ57以上へ追加8枚、下へ追加4枚の配分は、32回転の窓順では改善したが、再学習との組合せで既定配分を超えなかった。
- 実操作費用に必要紙数の罰則を足す正則化、学習回数の増加、長さ1までの再学習は安定した改善にならなかった。
- 最終状態のmandatory移動評価を区間加算として厳密に最小化するDPも実装したが、得点改善がほぼなく計算量が増えた。

試作は `round4_exact_*`、`round4_portfolio_*`、`round4_policy_*`、`round4_design_*` に保存している。提出版は外部ファイルや引数に依存せず、実注文を先読みしない。
