# AHC074 — Layered Barcode Display

AtCoder Heuristic Contest 074「Layered Barcode Display」の最終提出版を実装したC++プログラム．

白・黒・穴からなる紙を重ね，重ね順を変えてさまざまなバーコードを表示する．紙の模様と配置を工夫し，次々に届く注文を少ない操作で処理することを目指す．

## 問題概要

64個の窓を持つ表示装置と192枚の紙を使い，256種類の商品のバーコードを表示する問題．各紙の各位置には，白 `0`，黒 `1`，穴 `.` を指定できる．窓からは，その位置に穴がない最も手前の紙の色が見える．

最初に全商品のバーコードを受け取り，紙の模様を設計する．その後，1,024件の注文が1件ずつ与えられる．各注文では，窓から見えている紙を取り出して好きな深さに差し込み，指定されたバーコードを表示する．

紙の模様は最初に確定し，重ね順は注文の間も引き継ぐ．将来の注文が分からない状況で，正しい表示と総操作回数の削減を両立させる．

[問題文・公式ツール](https://atcoder.jp/contests/ahc074/tasks/ahc074_a)  


## 解法

処理は，注文を受ける前の**紙の設計**と，注文ごとの**操作列の生成**に分かれる．

### 1. 複数の商品で紙を共有する

商品のバーコードを主に表示する紙を「主紙」と呼び，次の構成を使う．

| 紙の役割 | 用途 |
| --- | --- |
| 専用主紙 | 1種類の商品を担当する |
| 共有主紙 | 2種類の商品を担当する |
| 裏紙 | 主紙の穴から見える色を補い，重ね順で表示を切り替える |

共有主紙には，2商品のバーコードで一致する色を印刷し，相違する位置に穴を開ける．その穴を下にある紙で補うことで，1枚の主紙を2商品に使う．

裏紙5枚・6枚の構成を候補にする．例えば裏紙6枚の構成では，共有主紙70枚と専用主紙116枚を使い，合計192枚で256商品を表現する．

### 2. 表示を切り替える窓と，紙を取り出す窓を作る

64列を並べ替え，2種類の構造を組み合わせる．

- **比較窓**では，白・黒を印刷した裏紙の前後関係によって，主紙の穴から見える色を切り替える．
- **階段状の構造**では，穴の位置をずらして主紙を取り出すための窓を確保する．同じ取り出し位置を使う主紙を，グループである「棚」にまとめる．

商品ペアと棚への割当によって，表示の切替費用や，目的の主紙を取り出すまでの手数が変わる．列の順序も含めてこれらを探索する．

### 3. 初期設計を探索する

| 手法 | 探索・評価する対象 |
| --- | --- |
| ビームサーチ | 比較窓に使う列と，白・黒を印刷する裏紙の組合せ |
| 焼きなまし | 商品ペア，主紙の棚割り，比較窓と階段側の列の入替 |
| 模擬注文によるシミュレーション | 複数の設計を使ったときの操作回数と配置の評価 |

主紙を取り出す費用，穴を補う費用，裏紙の並べ替え費用などを評価しながら，紙の設計を改善する．

構成や初期状態の異なる候補を作り，共通の模擬注文で比較して採用案を選ぶ．選択後も，シミュレーション中に観測した棚の状態を利用して，穴や初期配置を調整する．

### 4. 注文ごとに操作列を改善する

注文を受け取るたびに，次の処理を行う．

1. 商品に対応する主紙を取り出す．
2. 裏紙の順序を調整し，必要な色を表示する．
3. ほかの商品用の紙も補助紙として利用し，複数の窓をまとめて修正する．
4. 複数の操作候補を比較し，重複移動の削減や差し込み位置の調整で手数を短縮する．

補助紙を戻すか残すか，移動した紙をどこへ置くかによって，次の注文の処理しやすさが変わる．そこで，現在の操作回数に加え，棚の順序や補助紙の状態から推定した将来費用も評価する．操作列の短縮にはDPや局所探索を使う．

終盤は残り注文数に応じて棚の長期的な価値を弱め，最終注文では表示完成までの操作回数を優先する．各段階の探索量は残りの実行時間に応じて調整する．

## 実行方法

C++23に対応したGCCを使用する．最終提出ソースを `main.cpp`，公式形式の入力を `input.txt` に置いた場合の実行例．

```sh
g++ -std=c++23 -O2 main.cpp -o main
./main < input.txt > output.txt 2> run.log
```


ローカル入力ファイルには，商品一覧に続いて1,024件の注文が含まれる．プログラムは各注文を1件ずつ読み，操作列を出力して `flush` する．

| 出力先 | 内容 |
| --- | --- |
| 標準出力 | 192枚の紙の印刷内容と，各注文に対する操作列 |
| 標準エラー | 総手数と，設計選択・探索処理の診断ログ |

標準出力には紙の設計と各注文の操作列を，標準エラーには総手数と診断ログを出力する．出力の合法性と表示内容は，問題ページの公式ツールで検証・可視化できる．[公式ツール](https://atcoder.jp/contests/ahc074/tasks/ahc074_a)



## 主な実装

| クラス・関数・名前空間 | 役割 |
| --- | --- |
| `CoreGenesis<B>::generate` | ビームサーチによる比較窓の構築 |
| `refine_window_split` | 比較窓と階段側の列の入替 |
| `OrderMetric` | 裏紙の重ね順を変更する費用の評価 |
| `build_design` | 商品ペア，棚割り，紙の印刷内容の構築 |
| `OnlineRouter::query` | 複数方針による注文処理経路の生成と比較 |
| `OnlineRouter::route_state_value` | 棚と補助紙の状態の評価 |
| `bucket_mdp::Model` | 棚内の順序に対する価値推定 |
| `trace_shortener::optimize` | 同じ紙の重複移動を含む操作列の短縮 |
| `finish104::improve` | 最終注文の操作列の短縮 |
| `solve_case` | 初期設計から1,024件の注文処理までの制御 |
